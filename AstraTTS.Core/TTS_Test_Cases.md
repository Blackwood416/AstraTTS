# AstraTTS 多语言综合测试用例 (ZH/JA/EN)

本文档包含了用于验证 AstraTTS 合成质量、语言转换稳定性以及 G2P 处理能力的全面测试用例。

---

## 1. 基础功能测试 (Basic Functionality)

验证各语种纯文本合成的正确性。

| ID | 输入 | 语言 | 预期效果 |
|----|------|------|---------|
| B1 | `你好，欢迎使用AstraTTS。` | ZH | 纯中文，自然停顿，音质清晰 |
| B2 | `こんにちは、AstraTTSへようこそ。` | JA | 纯日语，重音正确，语调自然 |
| B3 | `Hello, welcome to AstraTTS.` | EN | 纯英文，发音地道 |
| B4 | `我是AI助手。` | ZH | 中英混合（缩写） |
| B5 | `私はAIアシスタントです。` | JA | 日英混合（缩写，片假名） |

---

## 2. 多语言混合测试 (Code-Switching)

验证不同语种在同一句子或段落中切换时的连贯性。

### 2.1 双语混合

| ID | 输入 | 组合 | 难点 |
|----|------|------|------|
| M1 | `这个feature很不错，我们可以加进PR。` | ZH-EN | 英文术语嵌入句中 |
| M2 | `今日のランチはHamburgerを食べました。` | JA-EN | 日英混合，动词接续 |
| M3 | `我刚才在听《さくら》，旋律非常优美。` | ZH-JA | 中日混合，日语歌名 |
| M4 | `OpenAI发布了最新的model。` | ZH-EN | 字母词+中文 |
| M5 | `駅の近くにStarbucksがあります。` | JA-EN | 日英混合，地名/店名 |

### 2.2 三语混合 (ZH-JA-EN)

| ID | 输入 | 难点 |
|----|------|------|
| T1 | `我在GitHub上看到一个日本のプロジェクト，非常Interesting。` | 三语快速切换，包含专有名词 |
| T2 | `使用Python处理日本語のテキスト是一个Common task。` | 技术术语+日语助词+英语名词 |
| T3 | `今天的感觉是Happy，明日も頑張りましょう，Keep going!` | 情感表达的跨语言切换 |

## 3. 边界条件与特殊处理 (Edge Cases)

### 3.1 缩写、大写与专有名词

| ID | 输入 | 难点 |
|----|------|------|
| A1 | `TTS, AI, LLM, GPT-4, ONNX` | 常见缩写拼读 |
| A2 | `AstraTTS, TensorFlow, PyTorch` | 专有名词重音 |
| A3 | `NHK, J-POP, AKB48` | 日系特定缩写 |
| A4 | `USA, UK, UN` | 国家/组织缩写 |

### 3.2 数字处理 (Numeric & Symbols)

| ID | 输入 | 领域 | 难点 |
|----|------|------|------|
| N1 | `2024年1月15日 14:30` | 时间日期 | 中/日读法差异 |
| N2 | `123,456.78元 / ￥12,800` | 货币 | 千分符与单位 |
| N3 | `成功率 95.5%，增长了 3倍。` | 百分比/倍数 | 符号处理 |
| N4 | `1つ、2つ、3つ、1人、2人、3人` | 日语计数 | 训读/音读切换 (关键测试) |
| N5 | `第1名 / 1位 / 1番目` | 序数词 | 语境判断 |
| N6 | `3.1415926` | 长小数 | 连贯性 |

## 4. 日语专项测试 (Japanese Specific)

重点测试日语 G2P (OpenJTalk) 的表现。

### 4.1 汉字多音字 (Homographs)

| ID | 输入 | 难点 |
|----|------|------|
| J1 | `明日、東京へ行きます。` | 「明日」(ashita) |
| J2 | `明日の予定を確認します。` | 「明日」(asu / ashita) |
| J3 | `銀行へ行く。` | 「行」(kou) |
| J4 | `三日間、旅行に行った。` | 「行」(it) |
| J5 | `名前は山田です。` | 地名/人名读音 |
| J6 | `昨日、今日、明日` | 时间词组合 |

### 4.2 促音、拨音与长音 (Phonetics)

| ID | 输入 | 难点 |
|----|------|------|
| P1 | `いってきます / いらっしゃい` | 促音 (っ) |
| P2 | `しんぶん / ほん / おんな` | 拨音 (ん) 在不同位置 |
| P3 | `お母さん / おじいさん / クーラー` | 长音标志 |

### 4.3 外来语片假名 (Katakana)

| ID | 输入 | 难点 |
|----|------|------|
| K1 | `コンピューター / インターネット` | 长片假名词汇 |
| K2 | `スマートフォン / ログイン` | 复合外来语 |
